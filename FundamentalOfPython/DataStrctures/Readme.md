# Data structures and its example in Python

Python offers several inbuilt DS
* String - Sequence of character , immutable. starts from index 0
* List - ordered collection of item
* Set- Unordered collection of data
* Touples - similar to list , but fixed data ( immutable )
* Dictionary - Key value pair wise storing data , like phone book ( name , number)
