# Conditional programming example in Python

Control structures are the building blocks of logic in programming. They help us decide what happens next in a program based on conditions or repetition. In Python, we primarily use three types of control structures:
* Conditional Statements
* Loops
* Functions

## Conditional Statements
* Use if, elif, and else to make decisions in code
## Loops
* Write for and while loops to repeat actions
## Functions
